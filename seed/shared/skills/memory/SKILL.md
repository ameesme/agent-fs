# Memory

`/agent/home/memory.md` is yours. It survives between runs; nothing else outside `home/` does.

Write a line when you learn something you would otherwise have to rediscover: where a repo lives,
which command actually works, a convention Mees insists on, a dead end not worth retrying.

Keep it short and factual. Group under `##` headings when it grows. Edit or delete lines that
turned out wrong — this is not a task log, and `done/` already records what you did.

Don't write: task summaries, timestamps, anything already in the repo, anything you only need for
the task you are on right now.
